# LinkedIn Strategy

LinkedIn is Nikolai's personal network, not a travel-intent audience like
Instagram. Don't reuse Instagram's "No Tourists Italy" ad voice or hashtags
here. Write as a personal founder update, first person, no hashtags, no
"link in bio." The ask is a soft one (an introduction, a question in the
comments), not "book now."

Same standing rules as everywhere else in this repo apply here, most of
which had to be relearned the hard way in the 2026-09-06 session that
started this file — see `CLAUDE.md`'s "Standing rules" section, which is
the durable source of truth:

- **Nikolai runs Rasna independently.** No co-founder, no partner, no
  profit split with anyone.
- **Don't name local collaborators** (Maria Grazia, Davide, Emiliano,
  Renzo, Nicolò) in outward copy by default. Describe activities
  generically (olive harvest, cheese tasting, leatherworking) instead of
  attaching a host's name, unless Nikolai explicitly asks for a specific
  name in that specific post. Their real involvement is often much
  smaller than earlier planning docs implied, don't guess at it or
  inflate it.
- **No em dashes anywhere** — same sitewide rule as the rest of the copy
  on this brand (`CLAUDE.md`'s design-language note). Rewrite grammatically
  instead. Legitimate en-dash numeric ranges ("6–10", "9–15") are fine.
